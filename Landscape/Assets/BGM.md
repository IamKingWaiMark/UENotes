# Overview

Background music


# Sound 2D

1. Open Level BP
2. Import a MP3 file
3. Call "Spawn Sound 2D"
4. Select the MP3 for the "Sound" Pin 
    - Optionally, promote it to a variable

## Looping

1. Open the imported MP3 file
    - Search for Looping and check it


## Switching Sound

1. From the Sound 2D object, call "Set Sound"
2. Set the New Sound

This will automatically play it

## Stop Playing

1. From the Sound 2D object, call "Stop"
